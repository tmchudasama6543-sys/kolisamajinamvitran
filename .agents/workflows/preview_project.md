# Preview Project Workflow

This workflow details the commands required to start the local development server for previewing/testing the project.

## Steps

### 1. Start Development Server
Start the development server with Turbopack enabled on port 9002:
```bash
npm run dev
```

### 2. View in Browser
Open the following URL in your web browser:
- [http://localhost:9002](http://localhost:9002)
